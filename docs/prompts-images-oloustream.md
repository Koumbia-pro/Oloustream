# Prompts de création des images Oloustream

Ces prompts sont conçus pour créer une série visuelle cohérente pour le site Oloustream. Utiliser le même style global pour toutes les images : photographie éditoriale premium, ambiance audiovisuelle africaine authentique, contraste cinématographique, palette noir charbon, rouge profond et touches de lumière chaude, rendu réaliste, composition professionnelle pour un site web.

## Règles communes à ajouter à chaque génération

```text
Photographie éditoriale premium et cinématographique, rendu photoréaliste, personnes noires africaines authentiques, ambiance professionnelle et chaleureuse, colorimétrie noir charbon avec accents rouges subtils et lumière chaude, détails réalistes, profondeur de champ maîtrisée, image haut de gamme pour le site d'une entreprise audiovisuelle au Burkina Faso. Composition adaptée à une bannière web, aucun texte lisible dans l'image, aucun logo, aucune marque, aucun filigrane, aucune déformation des mains ou des visages.
```

Format recommandé pour les bannières : **1536 × 1024 px**, paysage.

## Consignes finales pour toutes les images

- Ne jamais intégrer le texte de la page dans l'image : les titres seront ajoutés en HTML pour rester lisibles et accessibles.
- Ne jamais générer de faux logos ou de fausses marques sur les caméras et équipements.
- Garder la même colorimétrie : noir charbon, rouge profond, lumière ambrée.
- Prévoir des zones de respiration pour les titres et boutons du site.
- Générer en haute qualité et exporter en JPG optimisé pour les grandes photos, PNG uniquement si une transparence est réellement nécessaire.
- Me transmettre les fichiers avec les noms indiqués ci-dessus afin que je puisse les relier automatiquement aux bonnes pages.
